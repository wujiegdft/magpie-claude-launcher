连接配置

保存在此插件的 Magpie 选项中，保存后更新命令。不会测试网关连接。

默认取当前网页的协议、域名和端口。可覆盖为反向代理域名；识别失败时须手动填写。

在 VPS 的「Gateway → Gateway keys」创建，或运行 magpie gateway-key add "Claude Code"。不要填写网页登录密钥（MAGPIE_WEB_KEY）；Web 端口不接受占位值 magpie，即使地址是 localhost。

密钥会出现在上方命令、剪贴板和终端历史中；仅填写网关密钥。

请先在 VPS 启动 Magpie，并在运行命令的电脑安装 Claude Code。远程 API 须开启网络共享或设置 MAGPIE_ADDR 为网络监听地址；跨公网请使用 HTTPS / VPN。POSIX 前缀环境变量仅作用于本次 Claude Code 进程及其子进程，不改变当前终端环境；PowerShell 命令会修改当前会话环境变量，后续命令也会继承。
